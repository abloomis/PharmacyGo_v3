## Problem description
The problem our project is seeking to solve is the difficulty pharmacy students can face while studying for their exams. To facilitate this, we are continuing a previous capstone project to create a fun game for pharmacy students based on a database of information that can be used to help alleviate this issue. This will be done through a series of minigames and "battle"-like tests, inspired by classic Pokémon games.

## What the product must do: 
Provide a fun and informative way for pharma students to study exam material.

## How will you know: 
Playtesting. This will also include verifying that all of the study information is correct, as this is very important.

## Acceptance criteria: 
Ensure all pre-existing gameplay elements remain functional while adding desired minigames and new features.

## Constraints: 
- An inherited codebase
- Pre-existing database of information

## Specific Goals/FRs:
- FR-01 A functional tile-matching mini-game and attached question database.
- FR-02 A functional blackjack mini-game with associated question database.
- FR-03 Integration for these mini-games that allows for seamless access within the game world.
Each of these FRs has been confirmed with the project partner.
